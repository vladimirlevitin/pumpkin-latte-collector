## Требования и регрессии

| Область | Обязательное поведение | Исходная проблема / проверка |
|---|---|---|
| Группы | Независимое состояние любой доступной группы; нет названий групп в логике | В 0.5.23 hardcoded header fallback backpackIL |
| Автор поста | Собственный header, profile.php / people / groups/user / vanity; не автор комментария | 0.5.22: 0/50; 0.5.23: 20/20, достоверность отдельно |
| Дата | Сохранять источник, видимую метку, точность; не придумывать год/часовой пояс | Оба JSON: 0 точных дат; time комментария может попасть в пост |
| Текст | Полный доступный текст, признаки усечения; не смешивать header/comments | Нужны DOM fixtures длинных/коротких/media-only постов |
| Ссылки | Сохранять текст и адреса ссылок постов/комментариев, включая link-only | Fallback удаляет все a[href], schema комментария теряет links |
| Медиа | Связь с владельцем post/comment; без аватаров/emoji/UI; сохранять видео и исходные ссылки | Извлекаются img всех вложенных комментариев; нет video |
| Комментарии | Все доступные ветки, parent/reply, author/date/links/media; полнота не подменяется отсутствием ошибок | deep_done не доказывает полноту; нужны скрытые ветки/сортировка |
| Checkpoint | Точный ID, без числового сравнения ID, без обхода границы; задержки/виртуализация/пустой header | Имеется отдельный проверенный seek, требуется повторная интеграционная проверка |
| Restart | Сохранённый пакет не теряется при сбое между DB, checkpoint, export, download, watcher | finishBatch пишет checkpoint ДО подтверждения загрузки; exportComplete очищает DB |
| Две границы | Отдельно начальный верхний пост и хвост исторического сбора; незавершённое обновление не двигает подтверждённую верхнюю границу | В 0.5.23 одна точка на группу |
| Пополнение | От корня до прежней верхней границы; обновить её только после подтверждённого прохода; хвост не менять | Отдельного режима пока нет |
| Перестановки | Закреплённые/переупорядоченные посты не дают ложное доказательство непрерывности | Достижение одного ID не доказывает полноту всей ленты |
| Watcher | Стабильный файл → подтверждённый импорт → отдельный статус индексации; retry/restart без потерь | Есть staging watcher; изучить реальный launcher без запуска production |
| Импорт | Повторный пакет без дублей; дополнение записей, сохранение raw и provenance | Проверять локальным transport/SQL, production не менять |
| Поставка | Один ZIP после проверок, manifest в корне, отдельный Chromium, прежняя папка/ID | До готовности никаких промежуточных ZIP |

## Сделано в первом рабочем блоке

- Внутренний candidate основан на фактическом ZIP 0.5.23, тесты перенесены из ветки 0.5.22. Это не новая поставка.
- Удалён fallback автора, завязанный на название группы. Поддержаны собственные header profile.php/people/groups/user/vanity; данные вложенных комментариев не используются как metadata поста.
- Даты содержат published_label/published_date/date_precision/date_source. Точное время только из явного timestamp с timezone либо data-utime. Неизвестный год/timezone не выдумываются. Точное получение даты с живого Facebook ещё не подтверждено.
- В комментариях сохраняются links/media/date и неизвестные исходные поля. Ссылка-редирект Facebook раскрывается с сохранением исходного URL; текст ссылки не удаляется fallback-сборщиком. Тела постов/комментариев больше не обрезаются молча по 30k/12k; история вариантов не режется по 20.
- Media разделены между владельцами post/comment; исключаются profile links/avatars/emoji, добавлено video и dedup attachments/CDN URL. Это тестировано на DOM fixtures, не на живой странице.
- Снимки IndexedDB не удаляются после экспорта/восстановления/старта новой сессии. Экспорт фильтрует данные по текущему discoveryOrder.
- finishBatch больше не сдвигает checkpoint. export.js ждёт реального Chrome Downloads complete и считает SHA256. Worker атомарно фиксирует job/checkpoint/history/receipt. Квитанция скачивания не объявляется квитанцией импорта.
- При Deep failure сырой пакет сохраняется, checkpoint остаётся прежним, очередь failed posts повторяется после Продолжить. Закрытие feed во время Deep/export не уничтожает активную фазу.
- archive-state.js: чистый модуль двух границ с тестами. ВНИМАНИЕ: НЕ ПОДКЛЮЧЁН к background/popup; полноценного режима пополнения пока нет.
- Staging watcher: проверка production URL даже для custom client; включение индексации после import-only restart; повторная проверка hash после индексирования. 6 unit tests PASS. Установленный watcher и его production назначения не менялись и не запускались.
- tools/audit-bur-json.cjs проверяет оба приватных JSON без публикации их содержимого. 70 постов/539 комментариев: идентификаторы, тексты, имеющиеся авторы/ссылки/parent связи сохранены. Отсутствующие авторы/даты из JSON не восстанавливаются догадками.
- Дополнительно tools/test-private-dom.py исполняет код извлечения на ДВУХ настоящих сохранённых HTML Facebook из Downloads. Все script удаляются, сеть блокируется. В первом снимке: 4 поста/8 комментариев; metadata автора и метки дат 4/4. Во втором: 26/35; авторы 25/26 (часть анонимные с явным маркером), метки дат 26/26. Точных timestamp нет; это относительные видимые метки. Один автор оставлен unknown, не заменён произвольной строкой карточки. Снимки относятся к help.and.information, не к backpackIL; это дополнение, не доказательство работы текущего живого Facebook.
