FB Бур 0.5.22-alpha — проверенное локально ядро checkpoint

Это устанавливаемое Chrome-расширение. Это НЕ готовый универсальный сервис архивации.
База: canonical 0.5.20-alpha, c8fde0187dc7b0f845250114bfda042c060fb8f4.
Исходная папка 0.5.20-alpha не изменена.

Что изменилось
Только поиск checkpoint: каждый промежуточный участок наблюдается; скорость растёт
при подтверждённом смещении карточек. Потеря перекрытия вызывает возврат и уменьшение
шага. ID сравнивается точно, без предположений о числовой хронологии. Пакеты 10/50
означают количество проверяемых подшагов, а не скачок через невидимые посты.
Не найденный checkpoint даёт паузу. Он не заменяется последним собранным ID, поиск
не отключается после 36 проходов, сбор сверху не запускается под видом продолжения.
Отсутствие поста в наблюдаемой ленте не доказывает его удаление.

Границы проверки
17 тестов исходной 0.5.20 и 21 тест новой сборки PASS.
В отдельном Chromium проверены реальная установка, согласованность ping/manifest,
настоящий popup, Start, сохранение, reload/resume, точный checkpoint и перезапуск
профиля с сохранением ID. Проверены 4000 карточек в симуляции и 2100 наблюдений worker.
Работа новой версии на живой авторизованной Facebook-ленте пока НЕ подтверждена.
Полнота всех постов/комментариев НЕ гарантируется. Задержки свыше бюджета ожидания,
переупорядочивание и исчезновение карточек могут вызвать безопасную остановку.
Supabase/поиск/портал разрабатываются отдельно; в расширении нет серверных ключей.

Обновление — только когда назначен итоговый полевой тест
Не удаляйте установленный Бур с локальным архивом. Сохраните резервную копию текущей
папки расширения и JSON. Распакуйте содержимое ZIP В ПРЕЖНЮЮ папку расширения,
сохранив её абсолютный путь; затем chrome://extensions → Обновить у существующего
расширения. Не используйте «Удалить». Путь и профиль определяют ID распакованного
расширения; новая папка создаёт другое расширение и другое хранилище.
Обновление content script требует обновления вкладки Facebook; оно теряет живую
позицию, поэтому не выполняйте его во время незавершённого пакета.
Хранилища v0520/v05 намеренно сохранены для совместимости.

Кнопки и обычный сбор сохранены как в рабочей 0.5.20.
Откройте доступную группу → укажите точный checkpoint при необходимости →
«Начать / продолжить». Пока checkpoint не подтверждён, посты в пакет не принимаются.
Не нажимайте «Сбросить точку и историю ID» для устранения ошибки поиска.
