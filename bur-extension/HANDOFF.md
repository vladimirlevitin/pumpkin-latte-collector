# Актуальная версия FB Бур: 0.5.5-alpha

Каноническая ветка: `bur/canonical-0.5.5-alpha`.
Предыдущая версия: 0.5.4-alpha, коммит `f23d322aba6620ab7386bb9735c881c07b883794`.

- Полное расширение Chrome: [скачать ZIP](https://github.com/vladimirlevitin/pumpkin-latte-collector/raw/refs/heads/bur/canonical-0.5.5-alpha/releases/bur-collector-0.5.5-alpha-FULL.zip).

- Машиночитаемый указатель: [LATEST.json](LATEST.json).
- SHA-256 ZIP: `ca9a30fc8949ca4109533c19e1dc78b560ae81ee2c5092269b001dafc4119d8d`.

Исправления после живого прогона 0.5.4: parent_id берётся из comment_id при
наличии reply_comment_id; текущая короткая публикация внутри диалога допускается
в deep; посторонний диалог продолжает блокировать сбор; имя автора исключено
из поиска текста комментария; collector новых снимков соответствует 0.5.5-alpha,
в том числе после добавления комментариев из раскрытого диалога ответов.
Workflow, привязка к исходной группе/вкладке, автономная очередь и экспорт сохранены.

Проверки: 16/16 тестовых файлов PASS, включая 218 reply permalink из исходного
JSON и интеграционный сценарий «Посмотреть 2 ответа» в диалоге. Полный JSON
пользователя в репозиторий не добавлен. DOM-сценарии моделируются локально.
Выдаваемый ZIP распакован и загружен в отдельный Chromium с чистым профилем:
service worker подтвердил версию 0.5.5-alpha, popup открылся без ошибок JavaScript.
manifest.json находится в корне, все его ресурсы присутствуют.

**Живой Facebook после исправлений не проверен. Следующий шаг — пользовательский
контрольный прогон на 50 постах и анализ нового JSON. Не считать live-дефекты
подтверждённо устранёнными до этого прогона.**

Обновление: заменить файлы в прежней папке расширения, обновить карточку
в chrome://extensions и исходную вкладку Facebook. Сохранить папку и ID,
не удалять расширение с локальным архивом.

Это линия расширения 0.5.x; она не является букмарклетом «2.1.0-rc1».
Изменения отдельного букмарклета не заявляются как перенесённые.
