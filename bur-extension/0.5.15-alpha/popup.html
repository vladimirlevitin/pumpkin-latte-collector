Этап 1: только извлечение. Все публикации → полные тексты и доступные комментарии → JSON. Без ИИ и отбора по темам.

Подключаюсь…

После завершённого пакета Бур запоминает последний post_id для этой группы. Следующий «Начать» сначала находит его и продолжает со следующей публикации. Если точка не найдена, сбор безопасно останавливается. «Начать» сканирует ленту и при достижении лимита автоматически открывает по одному все найденные посты. «Закончить разведку» немедленно запускает подробный проход по уже найденным постам — второй кнопки не требуется. При ошибке одного поста сбор продолжается.

Сбор работает только с доступным в браузере Facebook. Полнота всех комментариев не гарантирована.
