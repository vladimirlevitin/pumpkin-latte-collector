Непрерывная сессия: вкладка ленты остаётся на текущем месте. Deep-проход выполняется в отдельной служебной вкладке. После каждых N постов JSON сохраняется автоматически, и следующий пакет начинается прямо после предыдущей границы. Возврат к корню и поиск checkpoint используются только при старте или аварийной потере позиции.

Сбор работает только с доступным в браузере Facebook. Полнота всех комментариев не гарантирована.
