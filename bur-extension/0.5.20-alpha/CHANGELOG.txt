FB Bur 0.5.20-alpha

Fix: continuous feed continuation after automatic JSON export no longer requires the previous batch boundary card to remain in Facebook's virtualized DOM.

- Feed content script exposes a per-document pageInstance and scrollY.
- Before deep extraction, background stores the live feed document identity and scroll anchor.
- After export, the next batch continues immediately when the same feed document and position are still alive.
- Checkpoint recovery is allowed only after a real feed loss/reload or missing root feed.
- Feed stalls, max-step exhaustion, and repeated obstructions pause safely when the live document is still intact instead of rewinding to the root.
- Regression covers b0001 -> b0002 -> b0003 with the boundary card absent from the DOM.
- Recovery regression verifies that replacing the feed document still triggers checkpoint recovery.
