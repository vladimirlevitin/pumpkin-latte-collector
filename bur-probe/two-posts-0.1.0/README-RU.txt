FB Bur Probe — 2 posts v0.1.0

Отдельный диагностический модуль. Он НЕ меняет и НЕ использует очередь основного FB Бура.

Жёстко зашиты два воспроизводимо проблемных post_id:
- 1761943778250990 — Daria Afonin Zolotina / Safe Haven for Donkeys
- 1763939851384716 — Yevgeny Frenkel / Ориониды

Что делает:
1. Пользователь нажимает одну кнопку.
2. Щуп открывает отдельную вкладку Facebook.
3. По очереди открывает только эти два permalink.
4. Для каждого делает 3 диагностических снимка DOM после загрузки.
5. Не раскрывает комментарии, не скроллит ленту, не сохраняет архив постов.
6. Записывает только структуру URL/dialog и короткие text_sample до 280 символов.
7. Автоматически скачивает один JSON.
8. Закрывает диагностическую вкладку и возвращает исходную.

Зачем три снимка:
Facebook/React может перестраивать dialog после события load. Нам нужно увидеть,
в какой момент detailDialog/target/obstruction меняют решение.

Алгоритм feed-scroll.js — точный snapshot из FB Bur 0.5.13-alpha.
