# «Иерусалим по-русски» — Chrome-коллектор v0.1.0

Основа: локальный коллектор Тыквенного латте v0.1.2, успешно прошедший короткий тест на 20 новых постах 23 октября 2026 года. Отдельная группа: https://www.facebook.com/groups/374040476267868/.

## Что делает

- Собирает посты, видимые комментарии, даты, ссылки на источники, метаданные изображений и авторов, которые Facebook уже отобразил участнику группы.
- Имеет контролируемую прокрутку, остановку, повторный запуск без очистки, дедупликацию и журнал ошибок.
- Хранит данные в новой IndexedDB `jerusalem_ru_archive` (не `pumpkin_latte_archive`). Ключи записей: `fb:374040476267868:...`, состояние Chrome: `jr_longrun_config`, глобальный объект: `__JR_FB_ARCHIVE`.
- После исчезновения группы из текущей вкладки приостанавливает процесс. Сохранение на диск — «Экспорт JSON» в панели на странице.
- Не вызывает Supabase: нет ключа, нет URL сервера, нет host permission и `SERVER_SAFE_INGEST_READY=false`. Отдельный серверный импорт будет следующим шагом после проверки пилота.
- В пассивном режиме НЕ обещает все комментарии к каждому посту: Facebook показывает лишь часть. Досбор веток нужно выполнять отдельно.

## Установка, Windows Chrome

1. Скачать архив `downloads/jerusalem-ru-collector-v0.1.0.zip` из этой ветки и распаковать в отдельную постоянную папку.
2. Открыть `chrome://extensions`, включить режим разработчика, нажать «Загрузить распакованное расширение» и выбрать папку, содержащую `manifest.json`.
3. Сохранить старое расширение и локальные данные ТЛ. Не запускать одновременно два длительных сбора в разных вкладках.
4. Открыть **в новой вкладке** https://www.facebook.com/groups/374040476267868/ и после загрузки нажать Ctrl+R.
5. Открыть значок **Иерусалим по-русски — коллектор ленты**, выставить **20** новых постов, нажать «Начать / продолжить».
6. После остановки нажать «Экспорт JSON» на странице Facebook и прислать файл на проверку. Не очищать данные Facebook и не удалять папку расширения.
7. После успешных 20 продолжать отдельными сериями 100, затем ориентировочно 400–500. Каждая команда Start запрашивает дополнительное количество новых постов.

## Ограничения

- Нужна обычная разрешённая пользователю сессия Facebook. Программа не обходит блокировки, ограничения доступа, скрытый контент или лимиты Meta.
- Прежде чем делать публичный поиск по материалам сообщества, нужно согласовать допустимость доступа, хранения и последующего использования контента, включая приватность участников.
- Статические тесты кода не заменяют испытания на реальной странице Facebook.
- Фото/видео не скачиваются как бинарные файлы, сохраняются доступные ссылки и сведения о них.
- Метция, существующие таблицы Supabase и архив ТЛ не изменяются.

## Проверки

Запустить `node --check` для четырёх JS файлов, затем `node jerusalem-extension/tests/isolation.test.mjs`. ZIP содержит плоскую папку расширения с `manifest.json` в корне после распаковки.
