# Pumpkin Latte Collector

Публичный репозиторий содержит код браузерного сборщика. Сами данные Facebook и серверные секреты здесь не хранятся.

## Установка bookmarklet

1. Откройте **BOOKMARKLET.txt**.
2. Нажмите **Raw**.
3. Ctrl+A → Ctrl+C.
4. Откройте свойства закладки **Pumpkin Collector**.
5. Полностью замените поле URL скопированным текстом.

## Запуск

1. Откройте группу Facebook «Тыквенный латте».
2. Нажмите закладку **Pumpkin Collector**.
3. Появится панель **Pumpkin Latte Archive**.
4. Оставьте открытым небольшое окно **Pumpkin → Supabase**.
5. Для контрольного прогона поставьте 10–20 новых постов и нажмите **Старт**.

## Что делает v2.6

- сохраняет посты, комментарии, медиа и авторов в IndexedDB;
- лучше извлекает даты из временных меток Facebook;
- отбрасывает служебные строки вроде `1 дн.` и `3 дн.` как ложные комментарии;
- постепенно раскрывает текст постов, комментариев и ветки ответов, не нажимая ссылки;
- сохраняет связь ответов с родительскими комментариями;
- после локального сохранения ставит пост в очередь синхронизации с приватным архивом Supabase;
- IndexedDB остаётся резервной копией, если синхронизация временно не прошла;
- кнопка **«Синхронизировать локальную базу → Supabase»** повторно отправляет несинхронизированные посты.

Синхронизация идёт через отдельное popup-окно и серверный relay. В bookmarklet нет service-role/secret ключа; используется только публичный publishable key, а приватная запись выполняется серверной функцией.

Gemini этим сборщиком пока не вызывается.
