Иерусалим по-русски · досборщик v0.1.0

Пилот на базе алгоритма досбора Тыквенного латте v2.8.2. Только группа 374040476267868.

ВАЖНО: перед запуском завершите уже идущую серию 100 постов в основном коллекторе v0.1.1; экспортируйте его JSON. Два расширения нельзя запускать на сбор одновременно.

1. Распакуйте ZIP в новую папку (не поверх основного коллектора).
2. Откройте chrome://extensions → режим разработчика → «Загрузить распакованное расширение» → папка с manifest.json.
3. Нажмите значок «Иерусалим по-русски — досбор комментариев»; выберите последний JSON основного коллектора.
4. Оставьте 20 и нажмите «Загрузить», затем «Старт / продолжить».
5. Будет открыта отдельная вкладка с постами. Расширение раскрывает текст и комментарии по одному посту; не закрывайте рабочую вкладку.
6. По окончании нажмите «Скачать отчёт»; откройте вкладку ленты Иерусалима и в основном коллекторе нажмите «Экспорт JSON» — сохранённые изменения в той же локальной IndexedDB jerusalem_ru_archive.
7. Пришлите оба JSON. Только после проверки первых 20 переходите к партиям по 50.

Ограничения: не загружает удалённые посты; при сомнениях в идентичности пропускает пост; сохраняет старые данные и дополняет увиденные комментарии. Не отправляет запросов в Supabase. Не использует базу или API Тыквенного латте. Данные остаются локальными и требуют последующего контролируемого импорта.

Проверка: статическая проверка синтаксиса JS, манифеста, списка файлов и контрольных сумм ZIP. Для проверки в реальном Facebook требуется установка пользователем.
