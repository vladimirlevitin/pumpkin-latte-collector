Исследователь глубин Facebook 0.1.1 — проверка поставки, 4 ноября 2026.

Автоматическая проверка: tests/test_installed.py. Распакованное расширение устанавливается в отдельный Chromium с временным профилем. Facebook подменяется контролируемыми страницами.
Проверяемые сценарии:
- вкладка Facebook открывается и прокручивается ДО установки расширения, наличие отсутствующего получателя подтверждается, затем реальный Start подключает сценарий без обновления страницы и сброса прокрутки;
- запуск через настоящий интерфейс расширения, движение от ленты к двум постам;
- более 1000 загруженных DOM-элементов комментариев, выбор всех комментариев, раскрытие;
- отдельное окно ответов, его закрытие и возврат к посту;
- сообщение «Страница сейчас недоступна» на открытии второго поста с HTTP 429;
- автоматическая остановка без перехода дальше и без автоматических повторов;
- ручной повтор того же поста с отдельным номером попытки;
- HTTP 503 в сетевом журнале; параметры URL и тела запросов не записываются;
- ошибка после раскрытия комментариев: последнее действие и интервалы времени сохранены;
- пауза пользователя, одиночный режим, несколько прогонов, перезапуск браузера и сохранность журнала;
- отсутствие текстов поста/комментария/ответа в журнале; цитата сообщения об ошибке внутри текста поста не вызывает ложную остановку;
- обычная веб-страница не имеет доступа к каналу управления расширением.

Итоговый журнал прогона и SHA-256 пакета — в репозитории docs/verification/DEPTH-EXPLORER-0.1.1.txt.
Живой Facebook этим ZIP перед передачей не проверен. Реальная причина ошибки не установлена. Нельзя считать fixture-проверки доказательством её устранения или универсальной поддержки всех вариантов Facebook.

История перед разработкой проверена: в origin/fix/bur-0525-story-message-body на момент проверки находится коммит e21b74e, Бур 0.5.34, с автоматическими перезагрузками при недоступной странице. Исследователь — отдельный продукт, без изменений Бура. При создании окна сначала открывает about:blank для регистрации вкладки, затем переходит по прямой ссылке; последующие переходы — tabs.update, ручной повтор — tabs.reload.
