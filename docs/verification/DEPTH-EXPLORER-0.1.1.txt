Исследователь глубин Facebook 0.1.1 — исправление запуска, 4 ноября 2026

Проблема пользователя: интерфейс показывает запущенный прогон, но постов/шагов/действий ноль. В 0.1.0 запуск только записывал задание; связь с уже открытой вкладкой не проверялась. Статические content_scripts не подключались к странице, открытой до установки расширения.

Воспроизведение: изолированный Chromium, страница группы открыта и прокручена на 400 пикселей ДО установки. Затем реальный ZIP 0.1.0 установлен через CDP Extensions.loadUnpacked. Подтверждено отсутствие получателя ping в старой вкладке. Нажат настоящий Start: спустя 15 секунд running=true, phase=seek, feedSteps=0, current=null. Регрессионный тест ожидаемо завершился ошибкой на старом ZIP.

Исправление: Start и Resume проверяют ответ сценария нужной версии. При его отсутствии подключают dom.js/probe.js через chrome.scripting без обновления страницы, затем проверяют ответ ещё раз. Задание создаётся после успешного подключения. Добавлены версия ping и защита от повторного запуска одного сценария. Ошибка команды в интерфейсе теперь остаётся видимой отдельно от обновляемого статуса. Адреса/область доступа к Facebook прежние; добавлено разрешение scripting для подключения к существующей вкладке.

Точный распакованный ZIP установлен в изолированный Chromium ПОСЛЕ открытия группы. tests/test_installed.py завершился с кодом 0:

PASS installed walk: >1000 DOM comments + sort + expand + second-post HTTP429/error stop; no content in journal
PASS no automatic retries; manual same-post reload recorded as attempt 2

PASS error after comment expansion records last action and both timing intervals
PASS browser restart: local journal + attempts + run history retained; ordinary page has no extension messaging access
PASS exact unpacked ZIP installed in isolated Chromium. Live Facebook NOT tested.

В сценарии также проверены отдельное окно ответов и его закрытие, сохранение позиции ленты 400 после подключения, отсутствие текстов публикаций/обсуждений в журнале. Для тестовой установки после открытия страницы используется Chromium с включённой отладкой расширений; пользовательский Chrome не управлялся. После перезапуска тестового браузера расширение повторно подключено с тем же путём/ID, журнал сохранился.

Живой Facebook этим ZIP не проверялся. Этот дефект запуска не устанавливает причину сообщения Facebook «Страница сейчас недоступна». Производственные системы и код Бура не менялись.

Обновление: поставить Исследователь на паузу, заменить файлы в прежней папке, обновить его в chrome://extensions, заново открыть панель и нажать «Продолжить». Папку/ID и ключи локального журнала не менять. Для 0.1.0 доступен обход: Пауза → обновить вкладку группы → Продолжить.
